# Project Documentation

This folder organizes repository documentation and attachment files by purpose.

## Structure

- `docs/attachments/`
  - `handoff/` — handoff and planning documents for the Mindframe project.
  - `setup/` — setup and guide notes related to Replit and frontend tooling.
  - `configs/` — preserved sample configuration files from attached assets.
- `docs/build-results/`
  - Build outputs and analysis artifacts such as typecheck reports.
- `docs/project/`
  - Project-level documentation describing repository setup and environment.

## Notes

- `typecheck-result.txt` is now stored under `docs/build-results/`.
